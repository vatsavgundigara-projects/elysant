# Elysant

Elysant is a lightweight Unity3D framework designed for building and managing modular gameplay systems.  
It provides utilities, managers, and helper components that can be reused across multiple projects.

---

## ⚙️ Features

- Modular component system  
- Event-based architecture  
- Scene and UI management utilities  
- Configurable game data pipeline  
- Editor tools for faster iteration
